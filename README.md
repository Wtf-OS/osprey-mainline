# Osprey mainline source checkpoints

Experimental Motorola Moto G3 2015 ports with ARM32 Android on ARM64 Linux 7.

- Android 17 / LineageOS 24.0: `lineage-24.0-mainline`, see
  [android17/README.md](android17/README.md).
- Android 16 / LineageOS 23.2: `lineage-23.2-mainline`, see
  [android16/README.md](android16/README.md).

Select matching component revisions and patches for the intended variant.
Kernel, firmware, modules and boot-package inputs remain external; this repo
alone is not a complete flashable ROM. Historical scripts outside the version
folders do not describe the current Android 17 packaging workflow.
