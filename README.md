# Osprey Android 16 mainline

Experimental LineageOS 23.2. The normal TWRP package writes system and boot,
uses the physical system partition as root and does not contain initramfs.
See android16/README.md. Android 15 scripts outside android16/ are retained
for history and are not the Android 16 packaging path.

Kernel, firmware, module and NDK Freedreno inputs remain external files;
this repository alone is not a complete ROM source checkout.
